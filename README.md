# m-alloc

An MVP web app for homeschooling that helps parents choose a curriculum, browse books, and create a weekly timetable for their child.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will start on `http://localhost:5173`
